# VIRTUAL VIGILANTES - Todo List Application

A full-stack Todo List Application developed using React, Node.js, Express.js, and MongoDB.

## Features

- User Registration
- User Login
- Secure Password Hashing using bcrypt
- Add New Tasks
- View Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed/Incomplete
- User-specific Tasks
- MongoDB Database Integration
- Responsive User Interface

## Technologies Used

### Frontend
- React
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Security
- bcryptjs
- CORS
